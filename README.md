# Color Lines

A browser remake of **Color Lines** (Gamos, 1992, MS-DOS), playable on PC and phones.

Move a ball to a free cell (it needs a free path). Five or more of one colour in a row, column or
diagonal vanish; otherwise three new balls appear. Beat the King's record.

```
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

Controls: mouse or touch; F1 help, F2 sound, F3 show next, F4 restart.
